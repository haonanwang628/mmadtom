# MMAD-ToM：框架与指标

## 一、框架

### 1. 概述

MMAD-ToM 是一个四轮的多智能体辩论框架，由三个学生模型参与，交替进行两种轮次：

- **同伴层面的心智建模（peer-level ToM）**：学生显式推断同伴的信念、推理、置信度和可能的误解，然后再决定是否修改自己的答案；
- **teacher 引导的纠正**：一个更强的 teacher 模型为每个学生分别建模其信念状态，并给出个性化的私下引导。

这一组"同伴–teacher"交互重复两次。第二次 teacher 轮会分析学生的完整推理轨迹，识别漂移、恢复和仍未解决的误解。每个阶段结束时，每个学生都产出一个新的状态：**答案、推理、置信度**。一个独立的 judge 评估每个状态是否正确，它不参与辩论。

**研究动机**：多智能体辩论中存在**谄媚漂移**（sycophantic drift），即学生原本答对了，却因为同伴给出不同的答案、表现得更自信或占多数，而改成错误答案。MMAD-ToM 的目标是测量这种漂移，并通过同伴心智建模和个性化 teacher 引导来缓解它。

### 2. 角色

| 角色 | 模型 | 职责 |
|---|---|---|
| 学生 ×3 | Mistral-7B-Instruct-v0.3、Phi-4-mini-instruct、Qwen2.5-7B-Instruct | 作答、建模同伴、根据引导复查 |
| Teacher | Gemma-3-27B-IT | 先独立解题，再分别为每个学生建模、诊断并给出引导；没有标准答案 |
| Judge | 规则评分为主，LLM 只用于抽取答案 | 独立判断每个状态是否正确；结果不回到辩论中 |

### 3. 流程

```
S0  独立作答        三个学生各自解题（与 Single-Agent baseline 使用相同的 prompt，含自我反思）
 │
R1  Peer-ToM 轮     学生看到两个匿名同伴的 S0 答案、推理和置信度
 │                  建模自己 → 建模每个同伴 → 自查 → 保留或修改                → S1
 │
R2  Teacher 轮 1    Teacher 为每个学生单独执行：
 │                  独立解题 → 建模学生的信念状态 → 诊断 S0→S1 的变化 → 私下引导
 │                  学生根据引导复查 → 保留或修改                              → S2
 │
R3  Peer-ToM 轮     学生看到两个匿名同伴的 S2（顺序重新打乱）                  → S3
 │
R4  Teacher 轮 2    Teacher 分析学生 S0→S1→S2→S3 的完整轨迹：
 │                  每次转变的方向和原因、引导是否被采纳、仍未解决的误解
 │                  → 最终私下引导 → 学生最终作答                              → S4
 │
Judge               独立评估 3 个学生 × 5 个状态
```

### 4. 信息隔离

每个阶段只引入一种影响，这样每次改答案都能归因到一个具体来源。

| 阶段 | 同伴的输出 | teacher 的引导 |
|---|---|---|
| S0 | 看不到 | 看不到 |
| S1、S3 | **看得到**（匿名、顺序随机） | 看不到 |
| S2、S4 | **看不到** | 只看到发给自己的那一条 |

另外：teacher 的引导不能泄露答案、不能评判学生的对错，也不能转述同伴写了什么；teacher 自己的答案和诊断只留作分析，不会传给学生。

### 5. 学生端：同伴心智建模（S1、S3）

学生必须按顺序写出以下分析，再给出答案：

1. **建模自己**：用一句话说明自己当前的答案，以及它依赖的关键步骤；
2. **建模每个同伴**：
   - 同伴持有什么答案、有多坚定；
   - 同伴**为什么**会得出这个答案，即它的推理背后是什么信念或推断；
   - 同伴的置信度是否有推理支撑。**置信度本身不是证据**；
   - 同伴可能错在哪一步；
   - 同伴的推理是否指出了**我自己推理中的具体漏洞**（是 / 否）；
3. **自查与决定**：逐一重做被同伴指出有问题的步骤。只有确认存在具体漏洞时才修改答案；"别人不同意"或"别人更自信"都不算理由。

### 6. Teacher 端

**基本立场**：teacher 是独立的推理者，不是 oracle。它先只根据题目自己解题，之后所有判断都用"与我的推导一致 / 有分歧"来表述，而不说学生"对"或"错"。

**Teacher 轮 1：信念状态建模（R2）**

teacher 依次完成：
- 题目真正在问什么，以及自己的解答；
- 学生现在相信什么、做对了什么、漏掉了什么；
- 学生是如何被同伴影响的。如果学生改成了某个同伴的答案，teacher 要**独立检查**那个同伴的推理是否真的更强；
- 诊断学生 S0→S1 的变化（见下表），并注明依据来自学生自己的推理、同伴的推理还是同伴的置信度；
- 按诊断结果给出私下引导。

| 诊断 | 判定条件 | 引导的做法 |
|---|---|---|
| 未改变 | 答案没变 | 与 teacher 的推导一致：让学生检查最不确定的一步；不一致：指出需要重新检查的步骤 |
| 有理由的修改 | 改了，并给出了在 teacher 推导下成立的具体步骤 | 让学生检查最不确定的一步 |
| 推理错误 | 改了，给出的理由是误读或算错 | 指出需要重新检查的步骤，不给出正确的数值 |
| 同伴从众 | 改成了同伴的答案，没有给出自己的理由 | 让学生回到自己之前的推理，说明之前到底哪一步错了 |
| 置信度驱动的顺从 | 同上，并且跟随的是置信度更高的同伴 | 明确指出"置信度不是证据"，要求学生找出同伴的推理暴露了自己哪一步的问题 |
| 无法解释的修改 | 改成了没有同伴给过的答案，也没有理由 | 问学生认为之前哪一步错了，并让它验证 |

**Teacher 轮 2：轨迹分析（R4）**

teacher 回顾自己在第一轮的分析，并查看学生的完整轨迹，然后：
- 对每次转变（S0→S1、S1→S2、S2→S3）标出方向（不变 / 漂移 / 恢复 / 换成另一个错误答案）和原因；
- 判断学生是否真的执行了第一轮的引导；
- 找出仍未解决的误解；
- 针对最近一次转变和这些误解，给出最终的私下引导。

**引导的统一规则**：
- 不泄露答案；
- 不引入学生看不到的数字；
- 不评判对错；
- 不转述同伴；
- 针对这个学生自己的步骤；
- 最多 4 句话。

## 二、指标

### 记号

- $A$：三个学生的集合；$D$：题目集合；一共有 $|A||D|$ 个"学生–题目对"。
- $r = 0, 1, \dots, R$，其中 $R = 4$：$r = 0$ 是 S0（辩论前的初始答案），$r = 1, 3$ 是 peer 轮，$r = 2, 4$ 是 teacher 轮。
- $\mathrm{correct}(a,d,r)$：学生 $a$ 在题目 $d$ 上第 $r$ 轮的答案是否正确。解析不出答案的，记为不正确。
- $\hat y(a,d,r)$：该轮的答案；$\mathcal{N}(a,d,r)$：学生 $a$ 在第 $r$ 轮作答前看到的同伴答案。

### 五个指标

**1. 每轮准确率 Acc(r)**

$$\mathrm{Acc}(r) = \frac{1}{|A||D|}\sum_{a\in A}\sum_{d\in D}\mathrm{correct}(a,d,r), \qquad r = 0,\dots,R$$

**2. 最终准确率 FinalAcc**

$$\mathrm{FinalAcc} = \mathrm{Acc}(R)$$

**3. 漂移率 DR(r)**：上一轮答对、这一轮答错的比例。

$$\mathrm{DR}(r) = \frac{1}{|A||D|}\sum_{a,d}\mathbb{1}\big[\mathrm{correct}(a,d,r-1)\wedge\neg\mathrm{correct}(a,d,r)\big]$$

**4. 恢复率 RR(r)**：上一轮答错、这一轮答对的比例。

$$\mathrm{RR}(r) = \frac{1}{|A||D|}\sum_{a,d}\mathbb{1}\big[\neg\mathrm{correct}(a,d,r-1)\wedge\mathrm{correct}(a,d,r)\big]$$

**5. 谄媚漂移率 SDR(r)**：只在 peer 轮 $r \in \{1, 3\}$ 计算，统计由对变错、**并且**新答案正好是同伴给出的答案的比例。

$$\mathrm{SDR}(r) = \frac{1}{|A||D|}\sum_{a,d}\mathbb{1}\big[\mathrm{correct}(a,d,r-1)\wedge\neg\mathrm{correct}(a,d,r)\wedge\hat y(a,d,r)\in\mathcal{N}(a,d,r)\big]$$

### 指标之间的关系

- 每轮准确率的变化等于这一轮的恢复减去漂移：$\mathrm{Acc}(r) - \mathrm{Acc}(r-1) = \mathrm{RR}(r) - \mathrm{DR}(r)$。
- $\mathrm{SDR}(r) \le \mathrm{DR}(r)$。$\mathrm{SDR}(r)/\mathrm{DR}(r)$ 表示这一轮的漂移中，有多大比例来自跟随同伴。
- 解析不出答案的输出按不正确计算：它会计入 DR，但不会计入 SDR，因为"没有答案"不可能等于某个同伴的答案。

### 每个指标回答什么问题

| 问题 | 指标 |
|---|---|
| 辩论整体是否提升了准确率？ | Acc(0) 与 FinalAcc 的对比 |
| 每一轮各有多少答案由对变错、由错变对？ | DR(r)、RR(r) |
| 同伴压力是否诱发了谄媚？漂移中有多少来自跟随同伴？ | SDR(1)、SDR(3)，以及 SDR / DR |
| teacher 轮是否带来了恢复？ | RR(2)、RR(4) |

### 与 baseline 的比较

| 方法 | 能计算的指标 |
|---|---|
| Single-Agent、iMAD | Acc(0)、FinalAcc、DR、RR |
| MMAD-ToM | 以上四个，再加 SDR |

- MMAD-ToM 的 S0 使用与 Single-Agent 相同的 prompt，因此两者的 Acc(0) 口径一致。
- 不同方法的轮次含义不同，所以跨方法比较时，使用 Acc(0)、FinalAcc，以及各轮 DR、RR 的加总。
- SDR 需要知道每个学生看到了哪些同伴答案，因此只用于分析 MMAD-ToM 自身。
